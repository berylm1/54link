Healthpoint — Healthcare Data Security

Live: healthpoint.newfire.app  ·  Video: healthpoint-walkthrough.mp4

Health information exchange and dispute resolution — deployed and demonstrated with a full logged-in walkthrough.

Architecture. React + Express + tRPC · ML-assisted

A platform for ensuring data security for healthcare institutions, utilizing machine-learning algorithms. Built on a React + Express + tRPC stack with end-to-end typed contracts and wired OAuth.

Key features

  • ML-driven security monitoring
  • tRPC end-to-end typed contracts
  • OAuth wired in

Problem it solves

Healthcare institutions handle sensitive data with weak security tooling — Healthpoint adds ML-backed protection.

Repositories. github.com/munisp/healthpoint

Meridian TaxTech — Nigerian NRS Unified Tax Platform

Live: meridian.newfire.app  ·  Video: meridian-walkthrough.mp4

Nigeria Revenue Service TaxTech compliance plane — six compliance modules, all reporting healthy.

Architecture. Go + Python · monorepo core, microservice planes, signed YAML rule packs, TigerBeetle ledger

The unified tax platform for Nigeria's Nigeria Revenue Service (NRS): a shared platform core (middleware spine, rule-pack registry, TIN graph, feature store, TigerBeetle ledger services), a compliance plane (e-invoicing T1/T2/T3, POS-VAT T6, WHT T7, TP/CbCR T8, ETR T9, CARF/VASP T10), a sovereign gov enclave (NRS analytics T4, JRB harmonisation T11, institutional case management T13, customs rails T15), and an inclusion plane (informal-sector onboarding T5, presumptive tax T12, taxpayer education T14 with agent app, USSD and white-labeling).

Key features

  • E-invoicing and MBS pre-clearance
  • Rev360 reconciliation workbench
  • Sovereignty boundary — gov enclave deployed separately
  • Signed versioned rule packs (rp-*) for VAT baskets, presumptive bands, ETR formulas
  • USSD + agent app for informal-sector inclusion

Problem it solves

Nigerian tax administration is fragmented across legacy systems and excludes the informal economy — Meridian unifies compliance, sovereignty, and inclusion into one platform the NRS can operate.

Repositories. github.com/munisp/meridian-core-platform, github.com/munisp/meridian-compliance-suite, github.com/munisp/meridian-gov-enclave, github.com/munisp/meridian-inclusion-suite, github.com/munisp/meridian-rule-packs

NDSEP — National Data Sovereignty Enforcement Platform

Live: ndsep.newfire.app  ·  Video: ndsep-demo.mp4

National Data Sovereignty Enforcement Platform — 18 operational sections captured in demo mode.

Architecture. TypeScript · full-stack, regulator-grade platform (NDPC-facing)

Nigeria's regulatory-grade platform for data protection compliance, breach management, and sector oversight under the Nigeria Data Protection Act 2023. Built for the Nigeria Data Protection Commission (NDPC). Includes real-time compliance dashboards cutting across finance, health, and education sectors, plus Healthpoint for healthcare-institution data security using machine learning.

Key features

  • Compliance management under NDPA 2023
  • Breach management and reporting pipelines
  • Sector oversight with real-time dashboards (finance, health, education)
  • ML-driven data security for healthcare (Healthpoint)

Problem it solves

Nigeria's NDPA 2023 created obligations but no unified enforcement tooling — NDSEP gives the regulator a single platform to register, monitor, and enforce data-protection compliance nationwide.

Repositories. github.com/munisp/ndsep, github.com/munisp/NGApp

UmojaFlowOS — Cross-Border B2B Payment Orchestration

Live: umoja.newfire.app  ·  Video: umoja-demo.mp4

Cross-border payment control for Africa-linked corridors — Nigeria, Kenya and South Africa.

Architecture. TypeScript · enterprise control plane

An enterprise control plane for Africa-linked cross-border B2B payment orchestration across Nigeria (NGN), Kenya (KES), and South Africa (ZAR). It coordinates regulated counterparties rather than replacing them.

Key features

  • Multi-currency corridors: NGN, KES, ZAR
  • Regulated-counterparty coordination model
  • Enterprise-grade orchestration layer

Problem it solves

Cross-border B2B payments in Africa are slow, opaque, and compliance-heavy — UmojaFlowOS orchestrates the regulated players instead of bypassing them, making corridors reliable.

VPP — Open Source Virtual Power Plant Platform

Live: vpp.newfire.app  ·  Video: vpp-demo.mp4

Virtual Power Plant control plane — live telemetry, asset management and power trading.

Architecture. TypeScript · MIT-licensed, device-protocol-native

An open-source virtual power plant platform: it registers distributed energy resources, forecasts and optimizes their dispatch, controls them over the protocols the devices actually speak, and trades the aggregated capacity.

Key features

  • DER registration and forecasting
  • Native device-protocol control
  • Energy trading on aggregated capacity

Problem it solves

Distributed energy assets (solar, batteries, EVs) sit idle and uncoordinated — VPP aggregates them into a dispatchable, tradable power plant.

Repositories. github.com/munisp/vpp
